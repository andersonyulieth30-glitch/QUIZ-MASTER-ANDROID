# QUIZ MASTER - paquete para compilar APK

Este repositorio contiene el código Flutter del juego y una acción de GitHub para compilar una APK Android en la nube.

## Cómo usarlo
1. Sube TODOS los archivos y carpetas de este paquete a la raíz de un repositorio GitHub.
2. Abre la pestaña **Actions** del repositorio.
3. Selecciona **Build QUIZ MASTER APK** y pulsa **Run workflow** (o espera a que termine el flujo iniciado al subir los archivos).
4. Cuando termine en verde, abre la ejecución y descarga el artefacto **QUIZ-MASTER-APK**.
5. Dentro encontrarás `app-release.apk`.

La primera compilación puede tardar varios minutos. La APK es para pruebas e instalación manual; publicar en Google Play requiere pasos adicionales.
